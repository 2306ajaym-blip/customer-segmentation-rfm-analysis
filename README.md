
# Customer Segmentation Analysis using RFM

## Overview
This project analyzes customer transaction data using RFM (Recency, Frequency, Monetary) analysis to identify customer segments and generate actionable business insights.

## Business Problem
Businesses often struggle to identify their most valuable customers and customers at risk of churn. This project helps classify customers into meaningful segments for targeted marketing and retention strategies.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Power BI
- Jupyter Notebook

## Methodology
1. Data Cleaning & Validation
2. Exploratory Data Analysis (EDA)
3. RFM Metric Calculation
4. Customer Segmentation
5. Dashboard Development
6. Business Insights Generation

## Customer Segments
- High Value Customers
- Loyal Customers
- Potential Customers
- At-Risk Customers
- Lost Customers

## Key Insights
- Identified customer groups contributing the highest revenue.
- Detected customers likely to churn.
- Supported targeted marketing and retention strategies.
- Improved visibility into customer purchasing behavior.
